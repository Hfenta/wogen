# Wogen

**Send money to your people.** Wogen (ወገን, "my people, my kin") is a prototype of an international money transfer app. It combines the best features of today's remittance apps: Express or Economy speed with an on-time guarantee, delivery to banks, mobile wallets, cash pickup and home delivery, live transfer tracking, a 30-minute rate lock, a clear breakdown of fees and exchange-rate markup, rate alerts, recurring transfers, airtime top-up, bill pay and family pooling.

> ⚠️ Prototype only. All exchange rates and fees are demo values, and no money moves.

## Live demo
https://hfenta.github.io/wogen

## Run it
Open `index.html` in a browser, or view the GitHub Pages deployment.

## Backend API
The `api/` folder holds the Wogen backend (Node.js + Express): quotes with rate lock, recipients, transfers, tracking and payout-partner webhooks. See [api/README.md](api/README.md).
